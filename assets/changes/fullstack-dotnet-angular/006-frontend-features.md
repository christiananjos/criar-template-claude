# 006 - Feature Frontend (Angular)

## Objetivo
Implementar uma feature completa no frontend Angular de `<nome do projeto>`, consumindo de ponta a ponta os casos de uso reais expostos pela API do backend.

## Escopo
- Entra: componente(s) smart/dumb, serviço consumindo a API real (não mock), formulário com validação.
- Não entra: alterar a API do backend além do que já foi definido na etapa 004.

## Entregáveis esperados
- Feature completa consumindo a API real, com tratamento de loading/erro no componente.
- Testes unitários dos componentes/serviços.

## Critérios de aceite
- [ ] Feature funciona ponta a ponta contra a API real (testado manualmente).
- [ ] Testes unitários cobrindo componente(s) e serviço.
- [ ] Estados de loading/erro tratados na UI (não só o caminho feliz).

## Skills relevantes
- `angular-scaffolding`
- `angular-unit-testing`
- `angular-accessibility`

# 003 - Feature de Exemplo

## Objetivo
Implementar uma feature completa de ponta a ponta em `<nome do projeto>`, servindo de referência replicável para as próximas features.

## Escopo
- Entra: componente(s) smart/dumb, serviço de dados (consumindo API real ou mock, documentando qual), formulário com validação (se aplicável).
- Não entra: novas features fora do exemplo escolhido.

## Entregáveis esperados
- Feature completa (`features/<exemplo>/`) com componente(s), serviço e testes.
- Padrão smart/dumb component documentado no README como referência.

## Critérios de aceite
- [ ] Feature builda e funciona (testada manualmente ou via teste automatizado).
- [ ] Testes unitários cobrindo componente(s) e serviço.
- [ ] `OnPush` change detection e `trackBy`/`track` usados onde aplicável (ver `angular-performance`).

## Skills relevantes
- `angular-scaffolding`
- `angular-unit-testing`
- `angular-accessibility`
- `angular-performance`
